# Self-hosted font sources

Imported on **2026-11-10** from the official Google Fonts CSS2 API and fonts.gstatic.com font assets. Font binaries are unmodified official WOFF2 files. The adjacent per-family OFL files retain the original copyright notices and redistribution terms.

The runtime stylesheet is `../../css/fonts.css`. Browser requests use same-origin assets; Google Fonts is not required while visiting the site. `manifest.json` records the exact source URL, size, SHA-256 and font-face uses of each file.

Included families: Barlow 300/400/500/600/700, Cinzel 400/600/700, Oxanium 600, Cormorant Garamond 600, Pirata One 400 and Uncial Antiqua 400. Google Fonts language subsets, including Vietnamese where provided by each family, are preserved in the CSS.

UTM Niagara and Niagara Solid remain device-local comparison fonts. They are not downloaded or redistributed here.

The adjacent `.gitattributes` preserves font binaries and upstream license bytes across checkouts. Upstream license whitespace is retained rather than reformatted, so the recorded SHA-256 values remain reproducible.
